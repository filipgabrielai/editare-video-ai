# Componente terțe

- **HyperFrames** (HeyGen), https://github.com/heygen-com/hyperframes, Apache-2.0. Instalat din npm.
- **GSAP**, https://gsap.com, licența standard GSAP. Instalat din npm.
- **whisper.cpp** (ggml-org), https://github.com/ggml-org/whisper.cpp, MIT. Pe Windows se descarcă arhiva oficială; pe Mac, din Homebrew.
- **Modelele Whisper** (OpenAI, MIT), în formatul ggml publicat pe https://huggingface.co/ggerganov/whisper.cpp. Se descarcă la instalare.
- **ffmpeg**, https://ffmpeg.org, instalat separat de utilizator; licența lui (LGPL/GPL, după build).
- **tests/date/proba.wav**: vocea lui Filip Gabriel Bara, 4 secunde din reelul demo, inclusă cu acordul lui, sub licența repo-ului.
- **Fonturile** Geist și Geist Mono (Vercel, The Geist Project Authors) și Instrument Serif (Instrument), licența SIL Open Font
  License 1.1: `fonturi/OFL-*.txt`. Fișierele woff2 sunt din Google Fonts.
- **Icoanele** din `stiluri/icoane.json` sunt din Lucide (https://lucide.dev), licența ISC; cele moștenite din Feather (de
  exemplu check, clock, code, link) sunt sub MIT. Ambele texte sunt în `licenses/LUCIDE-LICENSE`.
- **Sunetele** din `sunete/` sunt generate de repo din formule (`unelte/sunete.py`), sub licența repo-ului.
